# mylib

A simple JavaScript library providing basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling

## Installation

Install the dependencies with:

```bash
npm install
```

## Usage

Run the program with:

```bash
node main.js
```

## Test

Run the test with:

```bash
npm test
```

The test suite covers:

*Addition
*Subtraction
*Multiplication
*Division
*Division by zero
